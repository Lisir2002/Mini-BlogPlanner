# 更新日志

## 0.9.4

### 修复
- **静态压缩**：重新生成主题样式与图标雪碧图的 gzip 文件，避免线上继续命中旧压缩缓存。

## 0.9.3

### 新功能
- **独立错误页**：400、401、403、404、405、419、422、429、500、502、503、504 各自成页，统一奶油手账风格。

### 改进
- **错误页接入**：公开页与后台的 404、419、422、503 等文本响应全部改为主题页面，并保留具体原因与处理建议。
- **错误页插画**：新增锁、盾牌、警示、指南针图标，错误页按状态码使用独立配色与胶带装饰。

## 0.9.2

### 修复
- **回退重载**：回退切换 release 后同样重启 PHP-FPM，健康检查立即反映旧版本。

## 0.9.1

### 修复
- **升级重载**：切换 release 后重启 PHP-FPM，避免 reload 继续命中旧 realpath 缓存。

## 0.9.0

### 新功能
- **主题错误页**：404、405 和 500 统一使用奶油手账页面，保留导航与返回入口。
- **自绘控件**：后台输入框、下拉框和文件选择器统一自绘，浏览器原生外观不再出现。

### 改进
- **登录跳转**：登录改为整页跳转，避免异步登录后会话丢失，其他表单仍局部刷新。
- **上传提示**：超过 5MB 或类型不符时返回明确原因，前端直接提示。

### 修复
- **预览版号**：预览页页脚读取真实应用版本，不再显示 vpreview。
- **接口标签**：文章列表接口补齐标签，与详情接口保持一致。
- **标签维护**：重命名冲突、合并和空标签删除均通过实测。

### 安全
- **会话失效**：后台登录态过期时提示重新登录，不再误报操作完成。

## 0.8.5

### 修复
- **预压缩资源同步**：构建时从明文 CSS/JS 重新生成 `.gz`，浏览器不再拿到旧脚本，返回页面不会卡在过期遮罩。
- **返回快照隐藏**：页面进入后台缓存前先收起加载态，恢复时不会带着转圈快照回来。

## 0.8.4

### 修复
- **返回即时隐藏**：浏览器后退或前进复用已加载页面时直接隐藏加载态，不再对现成页面重复转圈。

## 0.8.3

### 修复
- **遮罩超时兜底**：加载态在 DOM 就绪或 1.5 秒后隐藏，内部跳转不再铺全屏遮罩，脚本异常也不会久转。
- **文档缓存稳定**：接口文档改用稳定脚本地址，升级后不再重复下载 5 MB 的 Scalar 包。

## 0.8.2

### 修复
- **升级后版本错位**：切换 release 后可配置运行环境重载命令，清掉 PHP-FPM 的 realpath 缓存，健康检查不再误报旧版本。

## 0.8.1

### 改进
- **接口文档加载态**：Scalar 渲染前显示奶油色加载卡片，脚本就绪后淡出，文档页不再出现空白等待。

## 0.8.0

### 新功能
- **加载态过渡**：全站首屏和站内跳转显示奶油色加载卡片，页面内容就绪后淡出，不再出现空白等待。
- **局部表单提交**：后台保存、归档、标签操作和审计筛选通过异步请求只替换主内容区，不整页刷新。
- **上传进度反馈**：媒体上传改用带进度的请求，显示百分比和结果提示，完成后只刷新媒体列表。

### 改进
- **无脚本兜底**：加载遮罩在禁用 JavaScript 时自动隐藏，表单仍保留原生提交路径。

## 0.7.1

### 修复
- **资源缓存失效**：主题资源 URL 带应用版本，升级后浏览器不会继续使用旧脚本和样式。

## 0.7.0

### 改进
- **依赖本地化**：Scalar 脚本与 Inter、JetBrains Mono 字体全部落到本站，文档页不再请求外部 CDN。
- **并行预载**：API 入口预载脚本与字体，主题样式与图标提前发现，减少首屏等待。
- **静态缓存**：Nginx 为脚本、样式和字体启用 gzip 静态压缩与长缓存，重复访问直接命中本地缓存。

## 0.6.1

### 修复
- **接口文档离线化**：API 文档改用本站 Scalar 资源，避免境外 CDN 不可达时页面只剩页头。

## 0.6.0

### 新功能
- **审计筛选**：审计页按事件名和操作者精确筛选，每页 50 条，超出页码自动夹到末页。
- **审计清理**：新增 `bin/audit-prune.php`，默认试运行，确认后按保留天数删除旧记录并写审计事件。

### 改进

- **审计入口**：后台导航的审计页展示总数、筛选条件和上一页/下一页，不再只读最近 100 条。

## 0.5.0

### 新功能
- **标签管理闭环**：后台支持标签重命名、合并与删除空标签，公开链接保持稳定。
- **文章预览**：后台可打开未发布文章，带 noindex 标记，不改文章状态。
- **审计日志**：新增后台审计页，记录登录、退出、发文、归档、媒体上传与删除。
- **媒体删除**：后台可删除图片并同步移除文件，文章引用会提示失效。
- **孤儿清理**：新增 `bin/media-clean.php`，默认试运行，确认后清理 24 小时前的孤立文件。

### 改进

- **发布目录构建**：新增 `bin/release.php`，生成带逐文件哈希和清单的不可变发布目录。
- **升级状态口径**：`status` 读取 current release 的应用版本，回退后不误报旧版本。
- **共享存储部署**：release 可复用部署根 `.env` 与 `STORAGE_DIR`，媒体、登录、备份和升级状态不落进发布目录。
- **后台导航**：新增标签、媒体与审计入口，保留文章列表、编辑器和预览的连续操作。
- **错误隔离**：审计写入失败不会阻断登录、发文或媒体上传。
- **版本同步**：应用升到 0.5.0，后台插件升到 0.4.0，奶油主题升到 0.1.3。

### 修复

- **升级备份调用**：备份步骤改用 bash 执行脚本，并显式传入 PHP 二进制与 PATH。
- **安装清单稳定**：安装完成后保留 `install.php`，由共享锁返回 404，避免发布文件哈希失效。

### 安全

- **响应头基线**：全站统一 nosniff、DENY、Referrer-Policy 与 Permissions-Policy。
- **媒体伪静态**：Nginx 示例为 `/media/` 增加优先动态路由，避免图片被静态规则截成 404。
- **发布清单校验**：上线前逐文件比对 SHA-256，篡改任一文件则拒绝发布。
- **删除边界**：删除媒体前校验 realpath 必须位于上传目录。
- **审计脱敏**：只记录动作、对象 id、状态和 IP，不记录密码或连接串。

### 已知问题

- **媒体处理**：暂无裁剪、缩略图和 WebP 自动转换。
